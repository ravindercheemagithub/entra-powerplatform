# Rebuilding the deck

`EntraSelfService-overview.pptx` is generated by `build.js` (pptxgenjs). `animate.py` then adds the click-to-reveal animations: every shape named `a<N>_…` fades in on click N.

Edits made directly in PowerPoint are usually simpler. Regenerate only for large changes, because regenerating overwrites hand edits.

```bash
# 1. Diagram images, exported from the draw.io sources at 2x into source/img/
X=/Applications/draw.io.app/Contents/MacOS/draw.io   # draw.io desktop
mkdir -p img
for pair in 2:components 4:sequence-approvals 5:sequence-create-app 7:flow-er02 10:lifecycle 12:security; do
  $X -x -f png -p ${pair%%:*} -s 2 -o img/${pair#*:}.png ../../../diagrams/entra-powerplatform.drawio
done
$X -x -f png -p 1 -s 2 -o img/future-sn-components.png ../../../diagrams/entra-powerplatform-future.drawio
python3 -c "import json,glob,os; from PIL import Image; json.dump({os.path.basename(f): Image.open(f).size for f in glob.glob('img/*.png')}, open('img/sizes.json','w'))"

# 2. Build, theme and animate (Node 18+; Python 3 with lxml)
npm install pptxgenjs@3.12.0 react-icons@5.3.0 react@18.3.1 react-dom@18.3.1 sharp@0.33.5
SKILL=/path/to/pptx-skill NODE_PATH=$PWD/node_modules node build.js ../EntraSelfService-overview.pptx
python3 animate.py ../EntraSelfService-overview.pptx
```

`SKILL` points to the folder that provides `scripts/apply_theme.js`, which writes the colours into the deck's theme. Without it, delete the `applyTheme` lines in `build.js` and set the theme colours in PowerPoint instead (**Design → Variants → Colors → Customize**):
- accent 1 `0079C1`
- dark 2 `003A70`
- light 2 `E8F3FB`
